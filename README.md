# Hello Kitty Mario Replica (In Progress)
# Project Overview
This is a 2D platformer game inspired by Super Mario, built from scratch using HTML, CSS, and vanilla JavaScript. The game features Hello Kitty-themed sprites and animations. It is currently a work in progress, aimed at showcasing my growing skills in game logic, event handling, and interactive front-end development.

# Features (Planned and In Progress)
- 2D platformer movement with keyboard controls
- Themed character sprites (Hello Kitty)
- Collision detection and level boundaries
- Coins or collectibles
- Score tracking and win/lose conditions

# Usage Instructions
To play the current build:

Clone the repository:
git clone https://github.com/sabrinalone45/hello-kitty-mario-replica.git

Navigate into the directory:
cd hello-kitty-mario-replica

Open index.html in a browser.

Live version for now (in progress): https://sabrinalone45.github.io/hello-kitty-mario-replica/
